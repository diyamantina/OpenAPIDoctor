# Support

Need help with OpenAPIDoctor? Here is where to go.

- **Questions and ideas**: open a [Discussion](https://github.com/mihaelamj/OpenAPIDoctor/discussions).
- **Bug reports**: open an [issue](https://github.com/mihaelamj/OpenAPIDoctor/issues/new/choose)
  using the bug form.
- **Feature requests**: open an issue using the feature form.
- **Security issues**: do not open a public issue. See [SECURITY.md](SECURITY.md).

Before filing, please search existing issues and discussions to avoid duplicates.
Clear, reproducible reports that include the offending spec (or a minimal slice of
it) and the exact `openapi-doctor` command get the fastest responses.
